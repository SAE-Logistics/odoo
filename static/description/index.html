Post Dated Cheque (PDC)

Post Dated Cheque (PDC) Management module enables businesses to register, track, and process post-dated cheques for customers and vendors with full accounting integration. It supports the complete PDC lifecycle from registration to deposit, clearance, or bounce, automatically creates journal entries, and reconciles invoices upon cheque clearance, ensuring accurate and controlled cheque-based payments.

Configure Google API Key

Go to Settings → Technical → System Parameters and add your Google Places API key.
Key: ps_partner_address_autofill.google_api_key
Value: Your Google Places API Key

Search Address in Contacts

Frequently Asked Questions

FAQs

1. What is this module used for?

This module integrates Google Places Autocomplete with Odoo Contacts, allowing users to search and select addresses that automatically fill City, ZIP, State, and Country fields.

2. How do I configure the Google API key?

Go to Settings → Technical → System Parameters and add:
Key: ps_partner_address_autofill.google_api_key
Value: Your Google Places API key

3. Which address fields are auto-filled?

When an address(i.e: street) is selected from the dropdown, the following fields are filled automatically:
City
ZIP / Postal Code
State
Country

4. Does this module work for all countries?

Yes. The module uses Google Places API, which supports global address data. Country and state detection is handled accurately based on Google address components.

5. What happens if I type in Street2?

Street: Updates full address details (City, ZIP, State, Country)
Street2: Updates only the Street2 field without overwriting other address fields

6. Does this module store Google data in Odoo?

No. The module only uses Google Places API for address suggestions and mapping. All address data is saved directly in Odoo after selection.
